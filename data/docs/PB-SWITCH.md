# PB-SWITCH — Halo S6 PCIe 6.0 Fabric Switch (Product Brief)

> Fictional company and products, created for a portfolio project.

## Overview
The HX-S6144 is a PCIe 6.0 switch with 144 lanes at up to 64 GT/s. Ports can be configured as x16, x8 or x4, for up to 36 ports. It is designed for AI servers that connect many GPUs, NICs and NVMe drives to one or more hosts.

## Latency and performance
Typical port-to-port latency is 95 ns in cut-through mode. The switch supports peer-to-peer traffic between endpoints (for example GPU to GPU) without routing through the host CPU.

## CXL
The HX-S6144 does not support CXL. It is a PCIe-only switch. It cannot be used for CXL memory pooling. For CXL memory expansion, see the HX-M2200 (PB-MEMORY).

## Power and thermal
Typical power is 42 W. Operating temperature range is 0 to 95 °C (case). A heatsink with forced airflow is required.
