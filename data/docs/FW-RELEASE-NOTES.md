# FW-RELEASE-NOTES — Halo R-Series Retimer Firmware Release Notes

> Fictional company and products, created for a portfolio project.

## Version 2.5.0
Improves FLIT-mode error logging on Halo R6. Minimum firmware version for HX-R6008 samples.

## Version 2.4.1
Workaround for erratum ER-R5-003 (Halo R5 rev A1 trains to 16 GT/s with SRIS clocking).

## Version 2.4.0
Adds receiver lane margining support in Halo Link Insight for Halo R5 and Halo R6.

## Version 2.3.2
Maintenance release. Lane margining is not available in 2.3.x.
