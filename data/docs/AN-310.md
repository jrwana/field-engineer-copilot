# AN-310 — CXL Memory Expansion with the HX-M2200 (Application Note)

> Fictional company and products, created for a portfolio project.

## Host requirements
For full features (hot-plug and multi-logical device pooling), the host must support CXL 2.0 or later. On a CXL 1.1 host, the HX-M2200 works for basic memory expansion, but hot-plug and MLD pooling are not available.

## Validated platforms
Halo maintains a list of validated host CPUs and BIOS versions. This list is available only under NDA through your account manager.

## Using a retimer in front of the HX-M2200
An HX-R5016 or HX-R6016 retimer may be placed between the host and the HX-M2200 to extend reach. Each retimer adds its typical latency in each direction (10 ns for Halo R5, 9 ns for Halo R6), on top of the controller's 85 ns load-to-use latency.

## Memory population
For best bandwidth, populate both DDR5 channels with identical DIMMs.
